# HoneyChain (BeeCrypt) SIH'26 — Master Remediation Plan

This baseline remediation plan tracks all 30 defects identified during the forensic audit (`HoneyChain_SIH26_Master_System_Audit_Report.pdf`), along with root causes, planned fixes, regression test strategies, and remediation status.

| ID | Severity | Category | Component | Root Cause | Planned Fix | Regression Test | Status |

| **HC-001** | P0 | Security / Integrity | `server/index.js`, `server/db/clean.js` | Unauthenticated public POST endpoint `/api/v1/health/clean` executes `TRUNCATE TABLE ... CASCADE`. | Removed endpoint completely from server Express routes; added `NODE_ENV === 'production'` abort guard in `clean.js`; removed frontend caller in `AppContext.jsx`. | `tests/security.test.js` asserts route absent from `server/index.js` and clean aborts on production. | **VERIFIED** |
| **HC-002** | P1 | Secrets Exposure | `server/.env`, `docs/SECRET_ROTATION_REQUIRED.md` | Live Neon PostgreSQL and MongoDB Atlas passwords committed in `.env`. | Strictly verified `.env` untracked in Git; created safe `.env.example`; created comprehensive `SECRET_ROTATION_REQUIRED.md` guide. | `git ls-files server/.env` returns empty; scan confirms no committed credentials. | **VERIFIED** |
| **HC-003** | P1 | Access Control / IDOR | `server/routes/batchRoutes.js` | `POST /batches` accepts arbitrary `producerId` from body without checking caller identity. | Bound `producerId` strictly to `req.user.actorId` unless user holds `admin` or `kvic` role.
